## 1. AUDIT PURPOSE

This audit answers one question:

> Can a Code 1 motorcycle learner or Code 2 light-motor learner rely on Mzansi Learner Driver for the complete published official learner-study scope, without a material NaTIS knowledge gap?

The audit does **not** attempt to reproduce confidential CLLT questions. It maps published learner knowledge.

## 2. SOURCE HIERARCHY

1. Current Western Cape learner-licence preparation requirements.
2. Current national learner-licence service information.
3. Official NaTIS learner manuals:
   - Rules of the Road.
   - Road Traffic Signs.
   - Vehicle Components and Controls.
4. Current National Road Traffic Act / Regulations where old manual wording or numeric/legal claims require confirmation.
5. Current physical learner pack/manual distributed in the Western Cape — edition/version still to be physically verified.

## 3. STATUS DEFINITIONS

- **COMPLETE** — applicable published knowledge is adequately available to Study and supported by Practice.
- **PARTIAL** — some knowledge is present, but the official section contains additional applicable learner knowledge.
- **STUDY GAP** — applicable published knowledge is not adequately taught in the app.
- **QUESTION GAP** — knowledge is taught but practice depth is insufficient.
- **ORIENTATION** — important learner/process information, but not part of the scored knowledge bank.
- **LEGAL REVIEW** — manual wording/value must be checked against current law before final inclusion.
- **OUT OF CODE 1/2 SCOPE** — genuinely heavy/specialised material not required for the Code 1/Code 2 gate.
- **PHYSICAL PACK CHECK** — published digital source is mapped but the actual distributed printed edition has not yet been visually/version checked.

# 8. CURRENT-SERVICE / CODE CLASSIFICATION CHECK

National current learner-service information still uses:
- Code 1 — motorcycle / tricycle / quadrucycle category.
- Code 2 — motor vehicles up to the 3 500 kg learner threshold.
- Code 3 — above that threshold.

This supports the app's Code 1 / Code 2 learner pathways. Provincial driving-licence pages may also display later driving-licence categories (A1/A/B/etc.), so the app must distinguish **learner-code pathway** from **eventual driving-licence category** and avoid conflating them.

# 10. AUDIT DECISION

## CURRENT DECISION: FAIL — REMEDIATION REQUIRED

This is not a failure of the app as a preparation tool. It means the stronger claim — **complete published official learner knowledge base** — is not yet proven.

### What is already strong
- Correct official three-domain architecture.
- 186-question source-controlled bank.
- Strong Rules core.
- Strong warning/sign/marking practice breadth.
- Complete identification of the official Code 2 control list.
- Complete identification of the nine official Code 1 controls.
- Offline Study/Practice/Mock/Readiness workflow.

### What blocks certification
1. Multiple Rules sections are absent or only partially represented.
2. Signs coverage is family-complete but not yet sign/meaning-complete.
3. Code 1 visual components are incomplete.
4. Official control-combination/application items are not exhaustively mapped.
5. Several 2012 legal statements require current-law verification.
6. Current physical printed-pack edition has not been directly verified.
7. Afrikaans and isiXhosa remain human-language-QA pending.
