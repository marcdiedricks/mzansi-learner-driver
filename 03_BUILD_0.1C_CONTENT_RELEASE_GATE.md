# BUILD 0.1C — CONTENT RELEASE GATE

**Project:** Mzansi Learner Driver — CLLT Prep  
**Project ID:** NKI-EDU-002  
**Status:** ACTIVE CONTROL — 0.1C

---

## PURPOSE

A learner-facing item must pass every gate below before it can move into the released offline question pack.

## GATE 1 — AUTHORITATIVE SOURCE

Pass only when:
- the concept comes from an approved source in the 0.1C Source Register;
- the source ID is recorded;
- a source locator or topic reference is recorded where practical.

Fail if:
- the item came from memory only;
- a commercial K53 app/book is the source;
- the item came from a leaked/recalled official test;
- source is unknown.

## GATE 2 — ORIGINAL WORDING

Pass only when:
- the question is written in original wording;
- the wording does not copy a confidential or proprietary question;
- the legal/safety meaning remains accurate.

## GATE 3 — ONE BEST ANSWER

Pass only when:
- one answer is clearly best;
- distractors are plausible but wrong;
- no option is accidentally partly correct.

## GATE 4 — EXPLANATION

Pass only when:
- the explanation tells the learner why the answer is correct;
- the explanation remains short and plain;
- the explanation does not merely repeat the answer.

## GATE 5 — ACCESSIBILITY / PLAIN LANGUAGE

Pass only when:
- sentence length is reasonable;
- unnecessary jargon is removed;
- the learner does not need audio to understand the item;
- an image is not essential unless the sign/marking itself is the tested concept.

## GATE 6 — VEHICLE SCOPE

Pass only when:
- the vehicle group is correct;
- Code 1 / Code 2 / Code 3 applicability is recorded;
- vehicle-control items are not incorrectly reused across vehicle groups.

## GATE 7 — CONTENT QA

Pass only when:
- source verification is complete;
- spelling/grammar is checked;
- answer index is correct;
- topic tag is correct;
- explanation matches the answer;
- no duplicate/near-duplicate exists in the pilot pack.

## GATE 8 — LANGUAGE QA

English source-master:
- plain-language review required.

Afrikaans / isiXhosa / later languages:
- competent human language review required before release;
- machine translation alone is never sufficient.

## GATE 9 — OFFLINE PACK TEST

Before release:
- package loads with Wi-Fi and mobile data OFF;
- question renders correctly;
- answer selection works;
- explanation works;
- progress saves locally;
- app still reopens offline.

## RELEASE DECISION

Only items with:

**SOURCE_VERIFIED → CONTENT_QA → LANGUAGE_QA (where applicable) → RELEASED**

may enter the public offline learner pack.
